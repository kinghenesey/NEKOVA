Everything Forged In

No frameworks. No configuration. No boilerplate. Write NEKOVA and the intelligence comes with it.

🧠
Native AI
Gemini, Claude, and GPT wired directly into the language. think is a keyword. No SDK setup, no API boilerplate.
🔗
Agent Pipelines
Chain AI agents with the -> operator. Output flows left to right through researchers, writers, analysts.
⚡
Parallel Execution
Run multiple AI tasks simultaneously with autonomous parallel. Built for speed, not callbacks.
💾
Persistent Memory
Data that lives between runs with memory blocks. No external store needed.
🔒
Sandboxing
Secure execution with sandbox strict and sandbox relaxed modes.
🌐
Web Framework
Real HTTP servers with routing, powered by Flask. Three lines to a running web app.
🗄️
Database
Full SQLite CRUD built into the standard library. Connect, create, insert, find — all native syntax.
👁️
Vision + Voice
Analyze images with vision_scan(). Speak and listen with native voice support. Multimodal by default.
🖥️
Web IDE
Browser-based editor with syntax highlighting, autocomplete, and a live terminal. No install required to try NEKOVA.

Get started

Install in Seconds

Two ways to run NEKOVA. Pick whichever suits you.

Via pip

Install
$ pip install nekova-lang
Run a file
$ nekova hello.nk
Open the IDE
$ nekova ide

Via GitHub

Clone
$ git clone github.com/kinghenesey/NEKOVA
Dependencies
$ pip install -r requirements.txt
Run
$ python main.py examples/hello.nk

Your .env file

.env — add one key, NEKOVA handles the rest
# You only need ONE key. # NEKOVA auto-detects and uses it. # Priority: Gemini → Claude → GPT → Mock GEMINI_API_KEY=your_key_here # Or Claude: # ANTHROPIC_API_KEY=your_key_here # Or OpenAI: # OPENAI_API_KEY=your_key_here
